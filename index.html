    Verbindung

    Alle Rezepte liegen in eurem GitHub-Repository. Auf diesem Gerät wird nur gespeichert, mit welchem Repository die App verbunden ist.

    Andere einladen

    Der Link enthält euren Zugangsschlüssel. Schick ihn nur an Leute, die mitschreiben dürfen.

    Verbunden bleiben

    Dein persönlicher Startlink verbindet die App bei jedem Öffnen automatisch, auch wenn der Browser seine Daten löscht. Öffne ihn einmal in Safari und lege ihn über Teilen → Zum Home-Bildschirm ab. Ab dann einfach über das Icon starten.

    Der Link enthält deinen Zugangsschlüssel. Nicht weitergeben, dafür gibt es den Einladungslink.

    Backup & Export

    Alle Rezepte auf einmal sichern. Zusätzlich speichert GitHub jede Änderung, nichts geht verloren.
